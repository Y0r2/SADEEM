# Gameplay verification checklist

- [ ] Roblox Studio opens `.rbxl` without load errors.
- [ ] No runtime errors in Output during tutorial and mission start.
- [ ] 1, 2, 3 and 4-player sessions tested (Studio Test > Server & Clients).
- [ ] Host can start the mission and other players join correctly.
- [ ] Moon and Mars branches are reachable and distinct.
- [ ] Base power/oxygen controls work and show meaningful trade-offs.
- [ ] Three message fragments spawn, can be collected, and solve the puzzle.
- [ ] 72-hour timer, hazards, failure, success and final report work.
- [ ] NASA facts have traceable source links; archived data are labeled archived.
- [ ] UI works on desktop/mobile; text legible to younger players.
- [ ] Roblox experience is public/accessible to judges with appropriate content rating.
